# joelevi.com

Personal digital business card for Joe Levi (static HTML on Vercel).

## Live
https://www.joelevi.com (apex redirects to www)

## Design
Blue / white digital business card (no dark/light theme toggle). Primary accent `#2F6FED`.

## Assets
- `index.html` — card UI
- `photo.jpeg` — profile photo
- `joelevi.vcf` — downloadable contact card
- `qrcode.min.js` — QR modal
- `joe-levi-public-key.asc` — PGP public key (joe@joelevi.com)
- `assets/theme.css` — single blue/white palette (legacy token aliases for inner pages)
